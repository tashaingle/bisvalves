# BiS Valves

Premium redesign of [bisvalves.co.uk](https://www.bisvalves.co.uk/), a specialist British precision-engineering website for high-pressure stainless steel flow control.

Built with Next.js and Tailwind CSS. Product copy, model numbers, certifications and literature links are taken from the live BiS catalogue.

```bash
npm install
npm run dev
```

Deployed on Vercel from the `tashaingle/bisvalves` GitHub repository.
